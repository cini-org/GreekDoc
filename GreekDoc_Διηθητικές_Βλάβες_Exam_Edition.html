2. Νεκροβιοτικές διαταραχές

Νεκροβίωση: παθολογική μεταβολή του κολλαγόνου του χορίου, συχνά με κοκκιωματώδη φλεγμονώδη αντίδραση γύρω από την αλλοιωμένη περιοχή.
SOS

Λιποειδική νεκροβίωση

  • Τυπικά κνήμες, συχνά αμφοτερόπλευρα.
  • Πλάκες ερυθροκαστανές/κιτρινωπές με ατροφικό κιτρινωπό κέντρο και πιο ενεργό υπερυψωμένο όριο.
  • Μπορεί να εμφανίσει τηλεαγγειεκτασίες και εξέλκωση.
  • Κλασική συσχέτιση με σακχαρώδη διαβήτη, αλλά δεν υπάρχει σε όλους.
  • Τραύμα μπορεί να προκαλέσει νέα βλάβη: φαινόμενο Koebner.

Μνήμη: «Κνήμη + κίτρινο ατροφικό κέντρο = λιποειδική νεκροβίωση».

Δακτυλιοειδές κοκκίωμα

  • Δακτυλιοειδής διάταξη μικρών, λείων, συμπαγών βλατίδων.
  • Συχνά ράχες χεριών/ποδιών, δάκτυλα, αγκώνες.
  • Το κέντρο συνήθως δεν έχει λέπια.
  • Η εντοπισμένη μορφή μπορεί να υποχωρήσει αυτόματα.
  • Η γενικευμένη μορφή έχει αναφερθεί σε συσχέτιση με διαβήτη.

Ρευματοειδή οζίδια

  • Υποδόρια, σκληρά οζίδια σε εκτατικές επιφάνειες και σημεία πίεσης.
  • Συνοδεύουν κυρίως οροθετική ρευματοειδή αρθρίτιδα.
  • Ιστολογικά: πασσαλοειδής διάταξη ιστιοκυττάρων γύρω από νεκροβίωση.

Νεκροβιοτικό ξανθοκοκκίωμα

  • Σπάνια διαταραχή, συνήθως σε μεγαλύτερους ενήλικες.
  • Κίτρινες/ερυθροκάστανες διηθημένες πλάκες, συχνά περιοφθαλμικά.
  • Ισχυρή κλινική συσχέτιση με παραπρωτεϊναιμία / μονοκλωνική γαμμαπάθεια.

3. Σαρκοείδωση και κοκκιωματώδεις διηθήσεις

ΝόσημαΚλινική εικόναΚλασικό exam clue
Δερματική σαρκοείδωσηΠοικιλία βλαβών: βλατίδες, πλάκες, οζίδια, διήθηση ουλών.«Μήλο-ζελέ» χροιά στη διασκόπηση· μη τυροειδοποιημένα κοκκιώματα.
Χειμετλώδης λύκοςΧρόνιες κυανέρυθρες διηθημένες πλάκες σε μύτη, παρειές, αυτιά, δάκτυλα.Χρόνια μορφή σαρκοείδωσης με δυσμενέστερη πρόγνωση και πιθανή προσβολή ανώτερου αναπνευστικού.
Νόσος CrohnΠεριπρωκτικές πλάκες/οζίδια, ρωγμές, συρίγγια ή μεταστατικές δερματικές βλάβες.Κοκκιωματώδης φλεγμονή σε ασθενή με εντερική νόσο.
Κοκκιωματώδης χειλίτιδαΕπίμονο, ανώδυνο οίδημα ενός ή και των δύο χειλέων.Μπορεί να αποτελεί μέρος του συνδρόμου Melkersson–Rosenthal.

Σύνδρομο Melkersson–Rosenthal

  • Κοκκιωματώδης χειλίτιδα
  • Υποτροπιάζουσα πάρεση προσωπικού
  • Πτυχωτή/οσχεοειδής γλώσσα

Τριάδα που αξίζει αποστήθιση.

Μικρό αλλά εξεταστικό

Η κοκκιωματώδης χειλίτιδα μπορεί να είναι μεμονωμένη ή να συνδέεται με Crohn/σαρκοείδωση. Η βιοψία δείχνει μη τυροειδοποιημένα κοκκιώματα.

4. Μαστοκυττάρωση

Μελαγχρωματική κνίδωση

  • Συχνότερη δερματική μορφή μαστοκυττάρωσης.
  • Πολλαπλές καστανές/ερυθροκάστανες κηλίδες ή βλατίδες.
  • Τριβή της βλάβης → πομφός, ερύθημα, κνησμός: σημείο Darier.
  • Στα παιδιά συχνά υποχωρεί· στους ενήλικες μπορεί να επιμένει και απαιτεί έλεγχο για συστηματική νόσο.

Διάχυτη δερματική μαστοκυττάρωση

  • Διάχυτη πάχυνση και διήθηση του δέρματος.
  • Μπορεί να σχηματίζει πομφό μετά από τριβή.
  • Κυρίως παιδική ηλικία.

Μαστοκύττωμα

  • Μονήρης ή λίγες κιτρινοκαστανές πλάκες/οζίδια.
  • Συχνό σε βρέφη/παιδιά.
  • Μπορεί να εμφανίζει θετικό Darier.

5. Ιστιοκυτταρικές διαταραχές

Νεανικό ξανθοκοκκίωμα

  • Καλοήθης ιστιοκυττάρωση της παιδικής ηλικίας.
  • Αρχικά ερυθρές βλατίδες που γίνονται κίτρινες/πορτοκαλί.
  • Συχνά κεφαλή, τράχηλος, άνω κορμός.
  • Συνήθως υποχωρεί αυτόματα.
  • Πολλαπλές βλάβες μπορεί να σχετίζονται με οφθαλμική προσβολή· απαιτείται κλινική επαγρύπνηση.

Ιστιοκύττωση από κύτταρα Langerhans

  • Ποικίλη νόσος: από εντοπισμένη δερματική έως πολυσυστηματική.
  • Δέρμα: σμηγματορροϊκού τύπου, εφελκιδοποιημένες/κρουστωμένες βλάβες, συχνά τριχωτό και πτυχές.
  • Μπορεί να προσβάλει οστά, πνεύμονες, υποθάλαμο/υπόφυση.
  • Κλασικό clue: άποιος διαβήτης σε πολυσυστηματική νόσο.

6. Αμυλοείδωση

Ορισμός: εξωκυττάρια εναπόθεση παθολογικού ινιδιακού υλικού. Η κλινική εικόνα εξαρτάται από το εάν η νόσος είναι εντοπισμένη στο δέρμα ή συστηματική.
ΜορφήΤυπική εικόναΠού;
Κηλιδώδης αμυλοείδωσηΚνησμώδης, κυματοειδής/δικτυωτή υπέρχρωση («rippled»).Άνω ράχη, μεσοπλάτια περιοχή.
Βλατιδώδης αμυλοείδωση / λειχήναςΠολλαπλές πολύ κνησμώδεις υπερκερατωσικές βλατίδες.Κνήμες, εκτατικές επιφάνειες.
Οζώδης αμυλοείδωσηΜονήρεις ή πολλαπλοί όζοι/πλάκες.Πρόσωπο, άκρα, κορμός· χρειάζεται αξιολόγηση για συστηματική συμμετοχή.
Πρωτοπαθής συστηματικήΠορφύρα, πετέχειες, κηρώδεις βλατίδες, μακρογλωσσία.Περιοφθαλμικά και πτυχές συχνά χαρακτηριστικά.

7. Λεμφοκυτταρικές διηθήσεις

Jessner–Kanof

  • Καλοήθης, χρόνια, υποτροπιάζουσα λεμφοκυτταρική διήθηση.
  • Λείες ερυθρές βλατίδες/πλάκες, συνήθως πρόσωπο, τράχηλος, άνω κορμός.
  • Χωρίς λέπια ή ουλοποίηση.

Δερματικό λεμφοκύττωμα

  • Καλοήθης ψευδολεμφωματώδης αντίδραση.
  • Ερυθροϊώδης βλατίδα/όζος, συχνά πρόσωπο ή λοβός ωτός.
  • Μπορεί να σχετίζεται με τσίμπημα, φάρμακο, tattoo ή Borrelia.

Ψευδολέμφωμα

Κλινικά και ιστολογικά μιμείται λέμφωμα, αλλά είναι αντιδραστική και καλοήθης διεργασία. Συχνά χρειάζεται στενή κλινικοϊστολογική συσχέτιση.

9. Οι 10 φράσεις που πρέπει να θυμάσαι

1. Κνήμη + κιτρινωπό ατροφικό κέντρο → λιποειδική νεκροβίωση.
2. Δακτυλιοειδείς λείες βλατίδες χωρίς λέπι → δακτυλιοειδές κοκκίωμα.
3. Περιοφθαλμικές ξανθές πλάκες + παραπρωτεϊναιμία → νεκροβιοτικό ξανθοκοκκίωμα.
4. Μη τυροειδοποιημένα κοκκιώματα → σαρκοείδωση.
5. Χείλος + πάρεση προσωπικού + πτυχωτή γλώσσα → Melkersson–Rosenthal.
6. Τριβή βλάβης → πομφός = σημείο Darier.
7. Κίτρινο οζίδιο παιδιού → νεανικό ξανθοκοκκίωμα.
8. Άποιος διαβήτης + δερματικές βλάβες → σκέψου Langerhans.
9. Rippled υπέρχρωση πλάτης → κηλιδώδης αμυλοείδωση.
10. Προκνημιαίες πλάκες φλοιού πορτοκαλιού + Graves → προκνημιαίο μυξοίδημα.
