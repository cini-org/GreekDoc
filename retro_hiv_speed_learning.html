Πλοήγηση

1. Τι πρέπει να ξέρω σε 3 λεπτά

Η παρουσίαση έχει πολλά ερευνητικά slides· εξεταστικά κράτα τον κορμό: τι είναι ρετροϊός, HTLV-1/2, HIV-1/2, CD4, μετάδοση, εργαστηριακή διάγνωση, θεραπεία.

Ρετροϊοί = RNA → DNA

Το κοινό χαρακτηριστικό είναι η αντίστροφη μεταγραφάση: μετατρέπει το RNA σε DNA, που μπορεί να ενσωματωθεί στο γονιδίωμα του κυττάρου ως προϊός.

Δομή που αξίζει

Έχουν περίβλημα, νουκλεοκαψίδιο, δύο μόρια μονόκλωνου RNA, tRNA και ένζυμα: RT, ιντεγκράση, πρωτεάση.

Γονίδια ρετροϊών

gag → δομικές πρωτεΐνες πυρήνα/καψιδίου.
pol → RT, integrase, protease.
env → γλυκοπρωτεΐνες περιβλήματος.

Παθογόνοι για άνθρωπο

HIV → ανοσοανεπάρκεια/AIDS, CD4 πτώση.
HTLV-1 → adult T-cell leukemia/lymphoma και τροπική σπαστική παραπάρεση.

HIV είσοδος

Κύριος στόχος: ενεργοποιημένα CD4+ T λεμφοκύτταρα. Είσοδος με CD4 + CCR5 ή CXCR4. Το env/gp120 συνδέεται με CD4/co-receptor.

Exam hooks

CD4 & CD4/CD8 → παρακολούθηση HIV.
p24 + Ab → αρχικός έλεγχος 4ης γενιάς.
HIV RNA → οξεία λοίμωξη / πολύ πρώιμο στάδιο.

3. Κύκλος HIV + πού πιάνουν τα φάρμακα

Αυτό είναι πολύ ωραίο για MCQ: αν ξέρεις το βήμα, ξέρεις και την κατηγορία φαρμάκου.

1. Είσοδοςgp120 + CD4 + CCR5/CXCR4 → entry/fusion inhibitors, CCR5 antagonist.
2. Reverse transcriptionRNA → DNA με RT → NRTIs / NNRTIs.
3. IntegrationDNA ενσωματώνεται → integrase inhibitors.
4. ΩρίμανσηΠρωτεάση κόβει πολυπρωτεΐνες → protease inhibitors.

Πορεία χωρίς θεραπεία

Οξεία φάση: υψηλό HIV RNA, πτώση CD4, μετά ασυμπτωματική περίοδος. AIDS όταν CD4 πέσουν έντονα, κλασικά <200/μL.

Οξεία HIV λοίμωξη

Συμπτωματική σε αρκετούς: πυρετός, εξάνθημα, λεμφαδενοπάθεια, φαρυγγίτιδα/έλκη/μυαλγίες. Αντισώματα αργούν — γι’ αυτό σκέψου RNA.

Περίοδος παραθύρου

Πρώτα εμφανίζεται HIV RNA, μετά p24, μετά αντισώματα. Άρα αρνητικά αντισώματα νωρίς δεν αποκλείουν οξεία λοίμωξη.

Πρόληψη

Συνδυαστική προσέγγιση: condoms, testing/counselling, θεραπεία ως πρόληψη, καθαρές σύριγγες, PMTCT, PrEP. Δεν υπάρχει κλασικό διαθέσιμο εμβόλιο λόγω γενετικής ποικιλομορφίας.
